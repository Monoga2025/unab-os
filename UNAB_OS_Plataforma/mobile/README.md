# 📱 UniNova Mobile · Universidad OS

Aplicación móvil nativa para estudiantes de Ingeniería UNAB desarrollada con **React Native & Expo**, implementando los estándares de **Diseño Web Luxury Pro Max** y el sistema de diseño de **Notion**.

---

## 💎 Características Principales:
1. **🏠 Tablero Semanal (Kanban Mobile)**:
   - Selector deslizante de días (`LUN`, `MAR`, `MIÉ`, `JUE`, `VIE`, `FIN`).
   - Tarjetas interactivas con tags pastel tipo sticker (`📚 Dinámica y Mecanismos`, `⚡ Circuitos`).
   - Prioridades dinámicas (`🔴 Alta`, `🟡 Media`, `🟢 Normal`).
   - Bottom Sheet estilo Notion para editar hora, ponderación, notas y acuerdos.

2. **📚 Mis Asignaturas**:
   - Catálogo oficial de Mecatrónica con conmutador de matrícula 1-Tap (`✅ Inscrita` / `➕ Inscribir`).

3. **⏱️ Bloque de Estudio Pomodoro**:
   - Temporizador regresivo en vivo de 45 minutos para sesiones profundas sin distracciones.

4. **🤖 Asistente Jarvis IA**:
   - Chat interactivo integrado con IA socrática especializada en cinemática (Grashof), circuitos (Thévenin/Norton) y cálculo.

5. **✨ Dock Flotante Luxury**:
   - Barra de navegación inferior flotante con bordes de vidrio sutiles, micro-interacciones táctiles y elevación sutil.

---

## 🚀 Cómo Ejecutar en Local:

```bash
# 1. Entrar a la carpeta mobile
cd mobile

# 2. Instalar dependencias
npm install

# 3. Iniciar el servidor Expo
npx expo start
```

### Opciones de visualización:
- **En tu celular real**: Abre la app **Expo Go** (Android/iOS) y escanea el código QR de la terminal.
- **En el navegador web**: Presiona `w` en la terminal para abrir la versión web responsive.
- **En emulador Android**: Presiona `a` en la terminal.
- **En simulador iOS (Mac)**: Presiona `i` en la terminal.
