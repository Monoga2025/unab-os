# lib

Shared server and domain logic.

- `supabase/`: Supabase clients (browser, server, admin) and auth helpers.
- `domain/`: learning, progress, feedback, Jarvis and academic-collaboration logic, plus seed data.
- `tema/`: TEMA integration (cloud sync, study briefs, evidence, token encryption).
- `jarvis/` and `telegram/`: the Jarvis bridge and Telegram link-code pairing.
- `ai/`: AI backends (Codex chat and app-server, AGY bridge).
- `entrenador/`, `academic-collaboration/`, `documents/`: practice prompts, collaboration dates and queries, and text extraction.
