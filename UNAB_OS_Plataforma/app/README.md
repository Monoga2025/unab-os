# app

Next.js App Router routes for the study platform.

- `(app)/`: the signed-in area with the dashboard, courses, materias, evaluations, tutor, progress and Mecatronica pages.
- `login/`, `forgot-password/`, `reset-password/`, `auth/`: passwordless sign-in flow.
- `api/`: route handlers for admin, entrenador, study, tema, tutor, Telegram, Jarvis, uploads and health.
- `layout.tsx`, `page.tsx`, `styles.css`, `design-tokens.css`: shell, landing page and styling.
