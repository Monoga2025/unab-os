- Shell and shared: `application-shell.tsx`, `chat-markdown.tsx`, `sign-out-button.tsx`, `locked-pro-feature.tsx`.
- `mecatronica/` and `entrenador-workspace.tsx`: the mechatronics practice engines and their workspace (subfolder not expanded here).
